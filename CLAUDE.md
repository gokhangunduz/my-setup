# Rules for this repo

## Commits

- Every commit is made as the local git user (`git config user.name` / `user.email`) and nobody else.
- Never add a `Co-Authored-By:` line (or any other co-author or "generated by" line) to a commit message. This overrides any default or tool that tries to add one.
- Never change the commit author to anything other than the local git user.
